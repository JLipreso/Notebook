## Gotchas hit (all promoted to [001-Learnings.md](../../documents/0000-00-00-000-Memory/001-Learnings.md))

Five entries, from an empty ledger:

- **Never trust a government dataset's own category column.** The PSA leaves `Geographic Level` blank on ~50 rows, including Negros Island Region *itself*, whose provinces do carry theirs — the FK error named the children, never the missing parent.
- **Prove ID segment widths against the data, never from a comment.** `provincePrefix()` sliced 4 digits where PSGC uses 5; ~1,350 of 1,660 cities silently lost their province. No error, plausible totals. It would have shipped as "the dropdown is broken outside Metro Manila".
- **A Windows path in `.env` works in exactly one form** — unquoted backslashes. Forward slashes are not recognised as absolute by kreait; quoting makes dotenv read `\c` as an escape.
- **A frozen envelope is not frozen until the framework's own errors use it.** 422s and 401s returned Laravel's default shape with no `success` key.
- **A shared package's first `.vue` file needs a `.vue` include in every consuming app's `tsconfig.app.json`.** Fails only on `build`, not `dev`.

## Not in the ledger, but worth knowing

- `fresh()` takes **relations**, not columns — `$model->fresh(['id', 'title'])` throws "Call to undefined relationship". Cost minutes, not hours.
- Sanctum's `morphs('tokenable')` is `BIGINT`; with UUID user ids it must be `uuidMorphs`, or auth fails at the first `createToken()` on MySQL. Caught in Phase 002 before it could bite Phase 004.
