## Gotchas promoted to [001-Learnings.md](../../documents/0000-00-00-000-Memory/001-Learnings.md)

One new entry this session:

- **`UploadedFile::fake()` cannot test MIME sniffing** — `Illuminate\Http\Testing\File::getMimeType()` returns the type guessed from the FILENAME, so a disguised executable passes a content-based check in tests that production would reject. Build a real `UploadedFile` over real bytes instead.

## Not ledger-worthy, but worth knowing

- **Tiptap resolves to 3.x, not 2.x** as the phase file assumed. StarterKit v3 bundles `blockquote`, `code`, `codeBlock` and `link` — none on our whitelist — so all four are explicitly disabled. **Anyone upgrading Tiptap must re-check what StarterKit includes**, or the editor will produce nodes the server silently strips.
- **PHP's built-in server needs `upload_tmp_dir` set explicitly on Windows**, or every multipart upload fails with "unable to create a temporary file". Not a code issue; it will bite on any machine testing uploads this way.
- **Three of my own Phase-009 tests were wrong in ways that would have passed.** Two asserted behaviour with an empty outbox, so the code under test never ran; one raced its own deferred. A green suite there would have proved nothing — worth remembering when writing tests for an orchestrator.
